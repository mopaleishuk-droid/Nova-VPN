# Nova VPN — zero-budget prototype

Это стартовый Android-проект Nova VPN.

Важно: текущая версия демонстрирует Android VPN Service и создаёт локальный тестовый VPN-интерфейс. Она НЕ предоставляет удалённый VPN-сервер и НЕ маршрутизирует весь интернет через другую страну.

Цель: собрать APK бесплатно, проверить интерфейс и затем подключить реальную серверную инфраструктуру, если появится бесплатный легальный ресурс.

## Сборка
Проект рассчитан на Android Studio / GitHub Actions. На телефоне можно загрузить проект в GitHub и использовать бесплатный GitHub Actions workflow после его добавления.

## Нулевой бюджет
Не покупайте сервер на этом этапе. Бесплатный сервер нельзя гарантировать навсегда; при подключении реального сервера нужно соблюдать условия провайдера и не использовать чужие ресурсы без разрешения.

## Следующий этап
Подключить реальный WireGuard/OpenVPN backend, затем добавить список серверов, конфигурацию, privacy policy и подготовить APK к распространению.
